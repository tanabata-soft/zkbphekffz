# デジタルシングルCD仕様

デジタルCDアルバムのシングル盤「デジタルシングルCD」の仕様。アルバムの下位版ではなく、表題曲を主役にした独立商品として扱う。エンジンはアルバムと共通（制作の流れは `docs/PRODUCTION.md` をそのまま縮小適用する）。ただし**形が違う**: ジャケットは短冊型、ブックレットは持たない。初回の制作時に、この形の違いをデータ駆動で切り替えられるようエンジン側へ分岐を入れる。

## 構成（全2曲・固定）

1. **表題曲**（1曲目に固定）
2. **カップリング曲**（2曲目に固定）

- インストゥルメンタルは収録しない。ボーナストラックも置かない。
- 尺の目安は全体で20分以内（2曲なら通常は10分前後）。
- 既存アルバムからのシングルカットも可。その場合、歌詞・同期データはアルバム版から流用し、裏面ノートの文章はシングル用に用意する（曲メモはアルバム版の曲解説から流用可）。

## データの置き方（src/album/）

- `album.ts`: `format` は「デジタルシングルCD」。カタログ番号は **NK-S001** からの連番（アルバムの NK- 連番とは別系統）。
- `tracks.ts`: 2曲を曲順どおりに置く。`bonus` は付けない。
- ブックレットは**持たない**（ブックレット画面自体なし）。ライナーや奥付に相当する文章は、裏面のパネル（次節）に置く。

## ジャケット（短冊型）

- 形状は**8cm シングルCD（短冊CD）そのもの**を模す。トップ画面のジャケット表示は実物の短冊ジャケットと同じ縦横比 **約1:1.938（およそ1:2）** の帯状にし、クリアケースのツヤと縁で「短冊ケースに入った紙ジャケット」の質感を出す（2026-11-04 オーナー指示）。
- 表の絵は、**実物の8cmシングルのジャケットを調べた「時代別の型」（docs/SINGLE-DESIGN-STUDY.md）から、作品の性格に合うものを選んで新規に作る**（2026-11-04 オーナー指示）。型A＝レーベル帯＋大きなタイトル＋表面クレジット（1988–91）、型B＝タイポグラフィ勝負（1992–95）、型C＝ファッション写真＋静かな文字（1996–99）。どの型でも**判型いっぱいに絵を使う**（黒の塗りつぶしで大きく空けない。意図的な余白として設計する場合を除く）。**折り目の演出は入れない**（オーナー指示）。題材はライナーノートの世界観から取る（曲ジャケットの融合や流用はしない）。
- 切り替え（タップ／横スワイプで裏面へ）はアルバムと同じ。

## 裏面（結合画像＋パネル）

ブックレットの代わりに、ジャケットの裏面は**各曲のジャケットを上下に並べた画像をベース**にし（多少の加工でよい）、その上にパネルを載せる（2026-11-04 オーナー指示。当初のノートブック面案から変更）。

- パネルにはライナーノートと、曲目（表題曲・カップリング）を載せる。曲目は**番号・タイトル・ジャンル・曲の長さ**のリストで、**表示専用**（タップで再生画面や曲目画面へは遷移しない。タップはジャケットの反転として扱う）。
- **バージョン情報は裏面パネルの下部に入れる。** 奥付に相当する情報（カタログ番号・形式名）はパネル上部に置く。
- トップ画面のボタンは**再生のみ**（曲目ボタン・ブックレットボタンは置かない。曲の切り替えは再生画面の前/次とリピート切替で行う）。曲目画面（裏ジャケット画面）はシングル形態では導線から外す（2026-11-04 オーナー指示）。
- **再生画面からトップへ戻ると、再生は止まる**（シングル形態の仕様。オーナー指示 2026-11-04）。トップのジャケットは、ボタンとインストール入口が収まる範囲でできるだけ大きく表示する。
- 背景（bg）はテーマ色の色面（恒常ルール）。アプリアイコンは表ジャケット（短冊）から作る（アイコン自体は正方形に切り出す）。

## 制作と公開

- 素材制作の確認ポイントはアルバムと同じ3か所。ただし確認ポイント①（ストーリーと曲順）は、シングルでは「表題曲とカップリングの組み合わせ」の確認に読み替える（曲順は構成で固定済み）。
- 公開はアルバムとは別のリポジトリ・別のアプリ ID で行う（手順は `docs/PRODUCTION.md` 後半のとおり）。
- 価格は商品化の時点で決める。目安として、CDシングル通常盤の相場（税込1,100〜1,650円）を参照する。
