# 8cmシングル ジャケット・デザイン調査

実物の8cmシングル（短冊）ジャケット写真を時代別に調べた記録。デジタルシングルCDの表絵を作るときの「型」として使う。
調査: 2026-11-04、実物写真 約20点（オークション・中古店・製品写真）。写真は制作フォルダの research/ と research2/ に保存。

## 時代別の型

### 型A: 1988–1991（黎明期・アイドル/歌謡型）

- ゾーン構成がはっきりしている：最上部にレーベル色の帯（ロゴ＋「タイトル／カップリング」の白抜き小字）、または細い帯。
- 主役はポートレート写真（全面）。タイトル文字は大きく、筆文字・極太ゴシック・スクリプト体など書体そのものがデザイン。
- 色面の帯を横に切り、文字が写真と帯の両方に重なるレイヤー構成が多い。
- 価格・品番・℗などのクレジット小字も表面に載る（商品記号が表に出ている）。
- 例: 田原俊彦『抱きしめてTONIGHT』(1988)、中山美穂『「C」/生意気』(1988)。

### 型B: 1992–1995（全盛期前半・タイポグラフィ勝負型）

- 写真主体は続くが、タイポグラフィがより大胆にデザイン化する。
- 全面フラットカラー＋巨大な数字・漢字タイポ＋俯瞰などの仕掛け写真（シャ乱Q『18ヶ月』）。
- スクリプト体の大文字が写真いっぱいに重なる（PRINCESS PRINCESS『Diamonds』）。
- セリフ体タイトル＋英字サブタイトル（WANDS）。一方で白地に余白を大きく取るミニマルな作例もある（B'z）。
- 例: 上記のほか T-BOLAN、FIELD OF VIEW などビーイング系は「写真＋帯＋ロゴ」の整った構成が多い。

### 型C: 1996–1999（全盛期後半〜末期・ファッション写真型）

- 大きく転換する。写真がファッション誌的になる：彩度を落としたトーン、顔のクローズアップ、左右ミラーリングなど、写真表現そのものがデザイン。
- 文字は小さく静かに：細いローマ字、字間を広げた表記、縦組み、端に寄せた配置。アーティスト名は小文字ローマ字で隅に。
- レーベル帯や表面のクレジットは姿を消し、情報は裏面へ回る。
- 例: 浜崎あゆみの一連（『poker face』『YOU』『Trust』『Depend on you』『TO BE』ほか、1998–99）。テープ状の帯に文字を載せる等のグラフィック遊びも。
- ただしアイドル/ポップ系では色鮮やかなデザイン系も並行して続いた。

## 時代を通じた共通項

- 主役は「1枚の強い写真（絵）」。文字は大きく叫ぶか小さく囁くかのどちらかで、中間の大きさは少ない。
- 縦長の帯という判型自体がデザイン要素（縦組み文字、上下のゾーン分け）。
- 裏面の定型は「写真（絵）の続き＋情報ブロック」。情報ブロック（品番・価格・バーコード・権利表記・STEREO/発売日）は上部か下部の帯に集約される（菅井えり裏面 1994、Sony盤裏面 1996/1999 で確認）。
- レーベルの帯・価格表記・レンタルシールなど「商品としての記号」も時代の記号として効く（型A/B）。

## デジタルシングルCDでの使い方

- 表絵は、作品の性格に合わせて型を選ぶ：賑やかでポップな曲 → 型A/B、静かで都会的な曲 → 型C、など。
- NK-S001『チョコミントの残像』は型A（レーベル帯＋大タイトル＋クレジット小字）で制作した（2026-11-04）。
- どの型でも、短冊の判型（約1:1.938）いっぱいに絵を使うことと、折り目の演出を入れないことは共通（オーナー指示）。
